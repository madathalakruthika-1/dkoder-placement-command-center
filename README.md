# Dkoder — Placement Command Center

A responsive Dkoder landing page and browser-only placement command-center prototype, built with React, TypeScript and Vite. The Round 2 experience extends the existing landing page rather than replacing it. Product and pricing details are based on the public Dkoder website; interface previews are labeled illustrative and do not imply real account data or employer affiliations.

## Interactive demo

- Select a preparation company, target role, package and skill focus; build a sample placement mission.
- Mark demo tasks complete to update illustrative readiness and XP. Mission checks persist locally in the browser only.
- Compare company preparation-focus illustrations and generate a sample adaptive-practice set.
- Use the practice terminal and timed mock preview. Terminal output is simulated; mock questions and scores are demo content.
- Explore the placement orbit, skill constellation, sample mistake notebook, readiness radar and fictional leaderboard.
- Switch tabs, company targets and planner controls with keyboard-accessible buttons and fields.

## Run locally

- `npm install`
- `npm run dev`
- `npm run build` to type-check and create a production build

## Notes

- Mission checklist state is stored in this browser only, not synced with a Dkoder account.
- Copilot, mock exams, code output, skill scores, and leaderboard entries are illustrative previews—not live AI, code execution, assessments, or real learner data.
- Practice-target company names describe preparation topics only, not partnerships or endorsements.
- Pricing shown is the annual pricing observed on dkoder.co.in and can change; verify current plans on Dkoder before purchasing.
