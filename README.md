# Dkoder — Placement Command Center

A responsive, interactive landing page concept for Dkoder, built with React, TypeScript and Vite. Product and pricing details are based on the public Dkoder website; interface previews are labeled illustrative and do not imply real account data or employer affiliations.

## Run locally

- `npm install`
- `npm run dev`
- `npm run build` to type-check and create a production build

## Notes

- Student checklist interactions are local demonstrations and are not saved to a Dkoder account.
- Practice-target company names describe preparation topics only, not partnerships or endorsements.
- Pricing shown is the annual pricing observed on dkoder.co.in and can change; verify current plans on Dkoder before purchasing.
